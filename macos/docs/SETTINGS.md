> Release scope updated 2026-10-21: [BETA1-RELEASE.md](BETA1-RELEASE.md) governs the basic public beta. Open advanced parity items below remain backlog, not automatic first-release blockers. Historical verification claims retain their original scope.

Pinned baseline: `1cd4620dd58a67b0963b73487743137813b8864a`.

Experience acceptance is independently tracked in [APP-EXPERIENCE.md](APP-EXPERIENCE.md) and [ISLAND-EXPERIENCE.md](ISLAND-EXPERIENCE.md). Native material is permitted; generic forms or different interactions do not satisfy the clarified Windows experience requirement.

This table distinguishes persistence from functioning services. A mapped property is not a completed feature. The two schema8 placement fields and JsonIgnore retired slots are not active Beta7 settings. Computed OriginalFontSize=FontSize and TranslationFontSize=0.875×FontSize are display rules, not serialized fields; lyric rendering remains incomplete.

Mac-only addition approved by the user on 2026-10-20: `AppSettings.lyrics.translationScrollMode`.
Default `adaptive` uses reliable current-line remaining time and actual translated text width;
`baseline` preserves the repeating24pt/s Windows Beta7 marquee. Music Settings exposes both,
with ten-language explanation of late/long-text limits and missing-timing fallback. Existing
settings merge the new default and preserve explicit choices through atomic saving. Rule/
settings fixtures and actual default/switch/persistence/pause/seek/untimed fallback have scoped
evidence in [LYRICS-DISPLAY.md](LYRICS-DISPLAY.md). This is an intentional behavior difference,
not a missing Windows setting or a substitute for missing lyric capabilities.
