# Windows v1.2.1

On 2026-11-25 the owner requested that the intermittent loss of the audio meter be fixed and the result published as Windows 1.2.1 Stable. The patch continues the established unsigned Windows distribution. The owner confirmed during the preceding 1.2.0 release that no signing credentials are available. The optional model inputs, historical model observations and experimental limitations are retained.

The owner also requested independent General settings switches for New File Relay and Devices & Sharing. Both pages are hidden by default and must stay visible while any feature on that page is enabled. The visibility switches use the native disabled state.
