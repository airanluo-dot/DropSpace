# Beta13 publication scope

The repository owner requested implementation of the supplied Beta13 development
package and publication after completion, with focused checks rather than full
regression or repeated model downloads. The continuing instruction is:

> 完成我一开始提交那个文件夹里的所有要求，已完成的部分不要重复修改或检查了，完成之后之后直接发布Beta13，中途不要因为我的新增或者改动要求打断

The package explicitly limits validation to necessary compilation, focused checks
and essential UI observation, excluding multi-model and multi-hardware matrices.
The owner also removed the model-side same-language skip marker and additional
prompt. Host-side language admission remains. Existing model and native runtime
bytes are reused. The AI feature stays optional and off by default on new installs.

This records authorization for the limited-validation experimental Beta13 release,
not general semantic approval. Existing incomplete full-song CPU/AVX2 and 7B
qualification remains disclosed. Minimal 1.8B CUDA Chinese translation succeeded
through the App service chain; it does not approve all hardware or translation
quality. See docs/dev/beta13-implementation.md for actual observations.
