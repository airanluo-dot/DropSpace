# Owner request: DropSpace 1.1 Beta4

On 2026-10-29, during the existing Beta4 liquid-glass and music-window task,
the repository owner explicitly instructed:

> 所有工作完成后，直接发布了，不用再找我确认了

This authorizes publication of the current `v1.1.0-beta.4` candidate after its
necessary checks. The exact version is the candidate in this task; it is not
represented as a separate version number quoted from the owner's message.

Beta4 adds the island liquid-glass material, bounded latest-frame capture,
refresh-rate tiers and expanded refraction-width control. It adds a Music Window
widget and visibility policy, initializes an unset translation target from the
interface language, and refines settings labels and alignment. Explicit and
legacy translation choices remain preserved. This is host/UI work, not a change
to translation inference, model identity, runtime bytes, prompt/output protocol,
whole-track admission, providers or cache contracts.

The previously accepted experimental model observations and limitations remain
verbatim. No new inference, model-quality acceptance, semantic approval or fix
for the previously reported native `0xc0000374` incident is claimed.

Focused local results are documented in `docs/dev/1.1-beta4-music-window.md` and
the Beta4 glass documents. Publication reuses those checks and unchanged runtime
and model bytes, then performs exact-main packaging, provenance, installer-payload
verification and public download/update readback. Broad functional/model suites
are not requested.
