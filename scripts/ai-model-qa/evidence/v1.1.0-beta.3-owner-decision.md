# Owner request: DropSpace 1.1 Beta3

On 2026-10-28, after the local Beta3 candidate and its completed checks were
reported, the repository owner explicitly instructed:

> 发布呀，直接，记得少做多余的测试

This authorizes publication of the existing `v1.1.0-beta.3` candidate through the
repository release workflow, reusing completed focused evidence. It supersedes
the earlier local-only delivery boundary. It does not authorize inventing tests,
new model-quality acceptance or resolution of the previously reported native
`0xc0000374` incident.

Beta3 changes bounded lyric discovery, explicit recording-name aliases,
same-source candidate quality, endpoint failure isolation, source-cache identity
and metadata-only candidate selection. The source review binds those host inputs,
including the alias JSON bytes and the selection protocol change. The shipping
translation models, native runtime bytes, translation prompt/output protocol,
whole-track AI admission and experimental model observations remain unchanged.
The candidate selector remains separate from translation inference; the production
media caller still selects Rules mode.

No new inference or semantic review is claimed. Historical model observations,
experimental limitations and their original acceptance remain verbatim. The
existing focused checks are documented in `docs/dev/1.1-beta3-lyrics-matching.md`;
release preparation performs only the necessary source/version binding, exact
package production, provenance and public readback checks. Broad functional or
model suites are not requested.
