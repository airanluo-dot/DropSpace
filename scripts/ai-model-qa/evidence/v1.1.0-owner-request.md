# Windows v1.1.0

On 2026-11-12 the repository owner requested that the actual functionality of the latest `v1.1.0-beta.8` be published as the `v1.1.0` Stable release, preserving Beta 8 and updating the official website and all corresponding version metadata. They clarified that the App and packages must carry the Stable version, rather than reusing binaries that still identify themselves as Beta 8. They explicitly requested no further tests.

Rebuild the same application functionality with Stable version and release-history metadata. Retain existing unsigned distribution when signing is not configured, unchanged model/native-runtime/CUDA bytes and the existing opt-in experimental AI limitations. Compilation, static package inspection, version/hash checks and public readback do not claim new functional or model validation. Do not execute an installer scenario for this release.
