# Owner authorization: 1.0.0 About logo patch

On 2026-10-22, after reporting the missing About logo in the installed 1.0.0 app,
the owner explicitly requested the smallest patch, direct modification of the
already published 1.0 release, and skipping all tests.

Only the About image loading changes: embed the existing 256-pixel logo and read
its bytes instead of resolving an ms-appx file path from a single-file build.
Version stays v1.0.0. Existing release assets, their checksums/update metadata and
the tag/source binding are replaced together under this explicit authorization.
Preserve the prior publication record and byte identities for traceability.

No unit, UI, installer execution, browser, model or regression tests are authorized
for this patch. Compilation, packaging, source/byte binding and public artifact
readback are production steps; they must not be described as functional passes.
Installer provenance records compiler inputs only, never a claimed installation.
Model inputs, native runtime bytes and the historical optional experimental model
limitations remain unchanged. There is no new semantic validation or acceptance.
