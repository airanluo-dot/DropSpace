# Owner request: DropSpace 1.0 stable host release

On 2026-10-22, the repository owner requested cache/DLC storage separation,
temporary removal of the System Activities interface and observers, a centered
branded About page, working automatic update installation without the existing
signature-only restriction, and a website audit with a matching, explicitly
unstable early Mac page. The owner explicitly instructed direct publication as
version 1.0 after those changes.

This request authorizes the stable host release. It does not create a new model
evaluation, assert a semantic pass, or rewrite the historical model acceptance.
The optional model weights, production prompt/runtime identities and original
Beta7 experimental observations are carried forward unchanged. AI translation
remains off by default, with its existing experimental limitations. The companion
review binds this request and the original review by SHA-256 and rejects a changed
model identity or fabricated acceptance. The source changes covered by this
release are described in `docs/dev/v1-release-2026-10-22.md`.
