# DropSpace encrypted Internet Share worker

This Cloudflare Worker is the reference backend for the v0.3.0-preview.6 encrypted Internet Share path. It stores only opaque ciphertext in R2. The AES-256-GCM master key is generated by the Windows client and remains in the URL fragment (`#k=...`), so it is never sent in an HTTP request.

The worker is intentionally not deployed by the repository workflow. A maintainer must create an R2 bucket, configure `wrangler.toml`, set a high-entropy `UPLOAD_TOKEN_SECRET`, review the Cloudflare account/network policy, and deploy it explicitly. Until that is done, the desktop app must keep Internet Share disabled; Nearby Share remains the local-LAN option.

## Local setup

```powershell
Copy-Item wrangler.toml.example wrangler.toml
wrangler r2 bucket create dropspace-share-preview
wrangler secret put UPLOAD_TOKEN_SECRET
wrangler deploy
```

Set the resulting Worker URL as the desktop backend URL. The backend endpoint must be HTTPS. Keep R2 lifecycle expiration enabled as a second cleanup layer; the Worker also checks the encrypted share expiry on every request.

The browser receiver uses WebCrypto, validates the manifest and each chunk hash, supports multiple files, and never renders a directory listing. Object names and upload metadata are bounded and authenticated. Logs must not include `#k=` fragments or request bodies.
