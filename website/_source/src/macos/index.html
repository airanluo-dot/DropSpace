02

Install on your Mac

  1. Download the DMG from this page or its linked GitHub Release. The release includes SHA-256 checksums for verifying download integrity.
  2. Open the DMG, drag DropSpace into Applications, eject the disk image, then open the copied app.
  3. If macOS blocks the first launch and you trust this download, open System Settings → Privacy & Security → Open Anyway, then confirm Open.
  4. Do not disable Gatekeeper, SIP or global security protections. A managed Mac may disallow this exception. Stop if macOS reports malware or damaged software.
