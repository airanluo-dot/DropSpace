Mac version

A native workspace for your Mac.

Requires macOS 26 or later and Apple Silicon. Intel Macs are not supported.

Mac v0.1.0 Beta 1 is a native public beta for everyday use, with Windows v0.3.2 Beta 7 as a functional reference, not a complete 1:1 port. Versions and updates are separate.

Not notarized by Apple. No Developer ID signature. Locally ad-hoc signed for bundle integrity; this does not authenticate the developer.

Native workspace

SwiftUI and AppKit bring file references, clipboard history, search, previews and local file actions to macOS. Each release documents its delivered capabilities and platform differences.

Install on your Mac

  1. Download the DMG from this page or its linked GitHub Release. The release includes SHA-256 checksums for verifying download integrity.
  2. Open the DMG, drag DropSpace into Applications, eject the disk image, then open the copied app.
  3. If macOS blocks the first launch and you trust this download, open System Settings → Privacy & Security → Open Anyway, then confirm Open.
  4. Do not disable Gatekeeper, SIP or global security protections. A managed Mac may disallow this exception. Stop if macOS reports malware or damaged software.
