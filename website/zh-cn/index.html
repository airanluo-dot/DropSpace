常见问题

你可能想知道。

DropSpace 是什么？

一个本地优先的 Windows 11 工作空间，用于临时保存文件引用和最近的剪贴板内容，并提供主窗口与屏幕顶部的灵动岛或刘海界面。

DropSpace 会移动我的文件吗？

不会。临时空间只保存引用。添加或移除引用都不会移动、复制或删除原文件。

可以添加文件夹吗？

可以。你可以通过拖放或选择器将文件和文件夹引用加入 DropSpace。

什么是剪贴板历史？

保存在本地的文本、网址、图片、文件和文件夹历史。你可以搜索、固定、暂停、清除并设置保留限制。

安装版和便携版有什么区别？

推荐的个人用户安装版提供开始菜单入口、独立卸载程序和原位更新；便携版无需安装即可运行，更新仅提供通知和下载。

DropSpace 支持 Windows 10 吗？

不支持。当前版本需要 Windows 11 版本 26100 或更高。

Windows 11 顶部拖放托盘怎么办？

Windows 可能会占用相同的顶部拖动手势。DropSpace 设置会链接到官方多任务页面；你仍可直接拖放到可见的紧凑或展开界面。

DropSpace 会上传剪贴板内容吗？

不会。常规内容功能只使用本地存储。启用更新检查后，DropSpace 只会访问公开的 GitHub Release 元数据和官方 GitHub 资源地址。

更新如何工作？

稳定通道只接收稳定版本；预览通道可接收稳定版和预览版。DropSpace 会验证下载大小和 SHA-256；当前未签名版本需要用户明确操作后才能安装。
