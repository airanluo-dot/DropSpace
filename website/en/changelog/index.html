CHANGELOG

What's new.

Stable releases for most users, plus an optional Preview channel for early builds. The main download always follows Stable.

v0.1.0StableAugust 11, 2026

First Stable Release

  • Final new DropSpace branding: the black-background Logo is the primary official presentation across the EXE, taskbar, tray, shortcuts, installer, uninstaller, MSIX, Share identity, and documentation. The supplied white-background version is retained as a fallback source and is not enabled by default.
  • Temporary Space with the top-center Dynamic Island or Notch, Compact/Expanded direct file drops, Explorer/Desktop drag and drop, pinning, external drag-out, and safe reference-only removal.
  • Clipboard History for text, URLs, images, files, and folders, with pause, retention, configurable capture limits, and local SQLite persistence. Consecutive copies of identical content now create one history entry; after different content is copied, the original content is stored normally again.
  • Windows 11 Drop Tray compatibility guidance. Windows may own the same top-edge gesture; Settings links to the official Multitasking page, while signed deployments can expose DropSpace through the standard Windows Share contract.
  • A standard per-user Inno Setup installer, custom install path, graceful in-place upgrades, independent uninstall, preserve-data uninstall, and explicit complete uninstall.

v0.1.0-preview.5PreviewAugust 9, 2026

DropSpace v0.1.0-preview.5

  • Visible Compact and Expanded Dynamic Island/Notch surfaces are now direct Explorer/Desktop file drop targets. Compact morphs into Drop Ready; Expanded stays open and displays an in-place drop highlight.
  • The passive top-edge activation HWND yields ownership while a visible Overlay is present, eliminating two OLE targets competing for the same pixels.
  • Temporary Space projections now use one authoritative mutation revision and a serialized/coalesced refresh coordinator. Removing the only item while Main Window and Expanded Overlay are both open no longer starts overlapping ObservableCollection resets.
  • Settings explains the Windows 11 Drop Tray conflict and opens the official Settings → System → Multitasking page. DropSpace does not probe undocumented feature flags.
  • The packaged app declares a Windows Share Target for StorageItems. A stable external-location identity package and signed-installer registration path are included for future trusted Artifact Signing.

v0.1.0-preview.4PreviewAugust 9, 2026

DropSpace v0.1.0-preview.4

  • Enlarged the event-driven OLE top-edge activation band and retained one native target from Explorer DragEnter through Drop, fixing hidden reveal and drop acceptance at the animated edge.
  • Kept the already-visible Island/Notch registered as an OLE target and routed every accepted path through the same Temporary Space repository pipeline as the main window.
  • Added a responsive two-row header below 860 effective pixels so high DPI, text scaling, and narrower windows no longer collapse the title and description into a one-character column.
  • Unified window, taskbar, tray, shortcut, installer, and uninstaller icon loading around the canonical multi-resolution icon embedded in DropSpace.exe.
  • Fixed identity-based projection updates so removing or pinning an item from the Overlay immediately updates the main window, and vice versa.

v0.1.0-preview.3PreviewAugust 9, 2026

DropSpace v0.1.0-preview.3

  • Desktop、Progman、WorkerW 和任务栏等 Shell surface 不再被误判为全屏应用；Temporary Space 有项目时点击桌面仍保持 Compact Island。
  • fullscreen suppress/restore、Drag reveal/leave、最后项目移除继续使用可中断 spring，不再一帧跳变。
  • 移除导致 Explorer/OLE 跳过目标的 HTTRANSPARENT。隐藏时使用 960 DIP 宽、仅 1 个物理像素高的可发现热边；真实 CFHDROP 进入后，同一 HWND 扩展到 760 × 112 DIP 并持有到 Drop/Leave。
  • 隐藏激活拖拽与已显示 Compact/Expanded Island 的直接 Drop 拥有明确且不重叠的 HWND target ownership；两者都进入现有 MainViewModel.AddPathsAsync，不会移动或删除原文件。
  • 所有 spring frame 输出先投影到 XAML/HRGN 安全范围，圆角不再因 Notch overshoot 变成负值；新增 1000 次中途反向模式压力验证。

v0.1.0-preview.2PreviewAugust 9, 2026

DropSpace v0.1.0-preview.2

  • 剪贴板通知改为 Windows 桌面标准的 AddClipboardFormatListener / WMCLIPBOARDUPDATE，增加有限重试、序列号去重、Pause/Resume、自写入抑制和监听健康诊断。
  • 顶部视觉 Overlay 与文件拖拽 Activation Host 完全分离。Temporary Space 为空时视觉 HWND 真正隐藏，不再用 3 像素 XAML 窗口冒充 Hidden。
  • 每个显示器使用独立、零 Alpha、无焦点的 Win32/OLE IDropTarget 激活区域；Explorer/Desktop 文件通过 CFHDROP 进入现有 Temporary Space 添加流程，原文件不会被移动或删除。
  • 移除 XAML 白边，并清除 HWND/DWM border、frame、shadow 痕迹；Hidden 时清空窗口 region 后 SWHIDE。
  • Width、Height、Top Offset、上下圆角、Opacity、内容 Reveal 和 Drop Feedback 改为可中断的真实时间 spring 目标，不再先跳到最终矩形后只做 Scale。
