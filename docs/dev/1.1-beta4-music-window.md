## Behavior and ownership

- Append widget ID 16 without renumbering existing IDs. It is an optional 1-by-1 library entry;
  adding it uses the existing vacant-cell policy and never rearranges saved tiles.
- Reuse MusicWindowService's single window. Its native visibility/minimize changes feed the
  dispatcher-owned IslandExperienceCoordinator. The opt-in setting defaults off and merges
  independently with concurrent material/settings edits.
- When enabled, visible-window suppression retires the old expanded/manual open, immediately
  dismisses automatic presentations and outranks resident, logo, media, notifications and volume.
  Manual retrieval and active file dragging may temporarily show the island. The existing position
  editor retains its temporary presentation. Minimize/close/disable re-evaluates current content,
  fullscreen and dismissal rules, without restoring stale expanded state. Reopening an already
  visible window through its widget also retires a temporary manual island open.
- New/unset translation choices follow the same effective interface resolution as the app:
  zh-CN/zh-TW use Chinese, others English. Persist an explicit-choice marker. Legacy saved targets
  migrate as explicit to avoid overwriting user intent; changing the target uses existing reload,
  cancellation and caching. No provider/model/inference code changed.
- Only shared settings-row vertical alignment and the main music page's empty-state/action-row
  alignment changed. The original island player layout and material pipeline are untouched here.
