# 1.1 Beta1 native music background integration

Local delivery only. The renderer project is `src/DropSpace.MusicBackground`; it supplies the
`DropSpace.App.Controls.MusicFlowBackground` control to the App-owned standalone music window.

## Source and native pipeline

The selected upstream is WXRIW/Lyricify-Backgrounds at immutable commit
`cbef8a667c02a01707c78c7e76dc67d65cf161ed`. The integration preserves its WinUI Direct3D 11
composition swap chain, dynamic mesh and HLSL calculations. It does not incorporate the upstream
player UI, global audio capture, session provider or URL loader. The background accepts artwork
bytes and a fresh amplitude from the existing DropSpace process-loopback owner.

The adapter fences asynchronous artwork changes, bounds input/decode size, removes render hooks
while hidden/unloaded, stops periodic updates for reduced motion, and disposes GPU resources.
Paused playback retains slow ambient motion; fresh audio amplitude expires after 450 ms. Device
recovery is bounded and GPU completion polling is capped at 100 ms. `FrameCount` counts actual
successful native presents; `IsReady`, `IsRendering` and `LastFault` expose honest runtime state.

Apache-2.0 copyright/license and modification attribution are in
`ThirdParty/Lyricify/LICENSE.txt` and `UPSTREAM.md`. No upstream NOTICE existed at the pinned commit.
