### 运行与授权边界

- 默认没有绑定时不创建 Agent 目录、不监听。只有本地 UI 创建绑定后才启动；启动恢复仍有效的 pending 或 paired 绑定。最后一个绑定删除后停止监听，pending 30 分钟到期后最多约 5 秒停止无授权 listener。
- 绑定创建、删除和发 key 不在 HTTP 命令目录中。配对前后是同一 binding ID；key 只返回一次且只能交换一次，host 文件只保存凭据摘要。Pairing 成功但客户端未收到响应时，需要通过本地 UI 删除并重建该绑定。
- 授权文件位于存储根 `Agent/bindings.json`，撤销日志为 `Agent/revoked-bindings.json`。损坏、超限、非法结构、重解析路径或写入失败均拒绝继续授权，不覆盖坏文件或静默重置。
- Windows Agent 目录 ACL 限定当前 Windows 用户和 SYSTEM，私有文件继承该 ACL。授权、撤销和 endpoint 临时文件使用随机文件名与 CreateNew；元数据刷新使用原子替换。endpoint 文件或存储祖先重解析路径不作为可信位置。
- 撤销先关闭该绑定的请求准入并取消其在途令牌，再以不可取消的提交尾段持久写入 binding ID 撤销日志，最后替换主快照。主快照因文件锁而无法替换时，当前进程 fail closed，重启仍使用日志拒绝旧授权。
- 若整个 Agent 目录拒绝所有持久写入，则任何实现都无法保证把新撤销记录写过重启边界。此时操作明确失败、当前进程拒绝授权；不能声称撤销已持久完成。修复权限/存储后需重新启动应用并确认撤销状态。损坏 store 的修复与重新授权没有隐式自动恢复入口。
- 授权是本机当前用户边界，不宣称隔离同一 Windows 用户下的恶意进程。停止请求和撤销向 App dispatcher 传递取消令牌，不能撤回已完成的副作用；不合作的 App 任务保留占用的并发槽直到实际结束。

### 固定协议与限制

发现文件 `Agent/endpoint.json` 只含 `protocolVersion`、`endpoint` 和 `processId`，无 key、token、绑定名称或资料。

| Route | 身份与结果 |
| --- | --- |
| `GET /v1/health` | 无授权；仅协议版本和 ready 状态 |
| `POST /v1/pair` | `{bindingId,pairingKey}`；返回同一 `bindingId`、`bearerToken`、`protocolVersion` |
| `GET /v1/catalog` | Bearer；返回 `{protocolVersion,commands}` |
| `POST /v1/execute` | Bearer；`{command,arguments}`，仅执行目录中明确声明的命令，返回 `{result}` |

错误统一为 `{error:{code}}`。Host 必须精确匹配实际 `127.0.0.1:<port>`；存在 Origin（包括 `null`）、Referer 或 Sec-Fetch-* 请求头时拒绝，无 CORS 放行。只接受无 Content-Encoding 的 application/json，对顶层重复或额外属性拒绝处理。请求体上限 1 MiB、响应上限 4 MiB、JSON 深度 32、最多 16 连接、4 个并发请求/实际执行任务，默认请求期限 30 秒，配对每分钟最多 10 次。响应超限先返回受控 413 `response_too_large`，不会发送部分 JSON 或将异常遗漏到宿主。

### 邀请提示词的剪贴板边界

代码审查确认，设置页复制邀请通过 `MainViewModel.CopyAgentInvitationAsync` 进入 `ClipboardCaptureService.CopySensitiveTextAsync`，设置 `ClipboardContentOptions.IsAllowedInHistory = false`、`IsRoamable = false`。这两个系统选项分别控制内容能否进入 Windows 剪贴板历史以及同步到其他设备，依据 [Microsoft 官方 ClipboardContentOptions 文档](https://learn.microsoft.com/en-us/uwp/api/windows.applicationmodel.datatransfer.clipboardcontentoptions)。

同一路径保留自身写入指纹，并增加 `DropSpace.Sensitive` 私有标记；读取剪贴板时先识别该标记并跳过，因此不依赖短期自身写入标记仍然有效。DropSpace 的自动跨设备传播订阅 `ItemCaptured`，该跳过路径不生成资料和捕获事件，保护应用自身的历史收集与自动传播。本节是代码路径审查，未据此宣称已实际验证 Windows 云剪贴板或跨设备链路。

这些设置和私有标记**不保证阻止第三方剪贴板工具读取或另行保存当前内容**；也不把 Windows 当前用户下的剪贴板描述为秘密隔离边界。邀请仍应仅用于本次配对，配对后使用已保存的加密凭据。
