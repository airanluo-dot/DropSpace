# DropSpace 1.1 Beta1 本地交付

本次交付包括四项资料工作流、本机 Agent 接入、独立音乐窗口，以及全 App 图标和主窗口尺寸改进。顶部灵动岛继续作为资料入口；版本显示 **1.1 Beta1**。没有推送代码、创建发布标签或 Release、上传分发包、更新网站、公开下载链接或自动更新源。仓库原发布流程与本次范围冲突的发布步骤未执行，本次停止边界为本地构建与验收。

## 已知边界

- 通用兼容指能够执行本机工具或 MCP 的 Agent；云端且没有本机执行器的 Agent 不能直接连接回环接口。MCP 桥需要本机 Node.js 18+，基础 PowerShell 客户端不需要 Node 或额外包。
- 外部写入若未被监听、且大小与修改时间都保持不变，元数据检查无法独立发现变化。没有全盘索引或持续哈希扫描。监听溢出、目录离线或数据库失败会给出状态，不能保证补收所有漏掉的事件，原文件保留。
- 若整个授权目录不可写，撤销会明确报错并在当前进程拒绝继续授权，不能声称已跨重启持久完成；修复权限后需重启并确认状态。授权边界是当前 Windows 用户，不隔离该用户下的恶意进程。
- 安装提示词复制使用 Windows 禁止历史/漫游选项和 DropSpace 自身捕获排除标记；第三方剪贴板工具不在此保护范围。后端、客户端、源依据和详细账本见 [Agent 交付记录](1.1-beta1-agent-integration.md)。
- 最终音乐图标和布局尚未完成新的像素视觉复核及截图：电脑控制工具在用户明确重新授权、重置 JavaScript 会话后仍返回实体 Esc 停止状态。已停止后续桌面输入，未把原生矩形断言当作视觉验收。新布局的真实按钮间距和动画中间帧已验证；长触摸、惯性滚动和全部 DPI/语言组合未实测。

正常使用前请从托盘退出原已安装版本，再启动便携 EXE。正常启动继续使用原 `%LOCALAPPDATA%\DropSpace` 配置；验收进程使用独立合成配置，未替换已安装版本。
