## Findings and fixes

1. Advancing `RELEASE_VERSION` alone would reactivate the large legacy suite and omit the independent CUDA descriptors. Added an exact Beta18 producer, extended the isolated CI route to Beta17/Beta18 and kept the required check name literal. Beta18 PRs compile full App/XAML without tests. Final main runs exactly eight selected Core cases, then packages. Release rejects missing exact-main producer evidence before any broad fallback. Metadata/checksums are promoted unchanged, with the descriptors and runtime publication receipt included in the eight public App assets.
2. The original promotion receipt carried no current focused-test evidence. Beta18 records actual TRX count/pass status and file hash, enforces the fixed pre-existing denominator of 2,124 and the eight-case filter, and binds results to exact main commit/tree. Promotion and the immediate prepublication check verify these bytes and the actual successful Windows producer. Private TRX/receipt/identity files stay in Actions artifacts; only the explicit eight public files are published.
3. The general release artifact-version script repeats four negative version fixtures. Beta18 uses only actual current executable identity assertions; the existing regression tests remain intact. Website suites remain skipped under this release's limited validation policy, while synchronization, static build, deployment and public metadata checks remain required.
4. The legacy portable smoke executes thousands of lifecycle/stress iterations and would violate the requested focus/budget. Beta18 inspects the actual final single-file assembly statically. The one isolated installer install/payload/uninstall scenario is retained and counted separately by the task's validation ledger. Process handles from that scenario are disposed.
5. The release-action contract introduced by PR #109 had an exact Beta17 asset predicate. Updated the existing assertions to the intentional exact Beta17/Beta18 predicate, preserving action v3.0.3 SHA, metadata inputs and public inventory. Historical Beta17 route assertions now reflect the shared isolated job and retain their original purpose. No tests were deleted or executed for these adjustments.

CUDA archive/manifest/cache identity is unchanged: component `cuda-llama-cpp-v0.5.0-cuda13-win-x64-v1`, archive 540,873,572 bytes, SHA256 `79e8deb4f8c35e7c9c94da0efa0752826bafe510fcb1e54da23062f2d6f40a0b`. This route stages only the small App-bound descriptor; it does not download, rebuild or upload the CUDA archive.
