# Version 1.0 release execution record

The owner requested the five application/website changes and direct publication
as the first 1.0 stable release on 2026-10-22. Immediate baseline:
`v0.3.2-beta.7`; integrated starting main: `0833b5bb395ea382a6b9e5e10ab943698290ae42`.

## Result and boundaries

- General settings measure non-DLC cache/data. DLC totals include models, runtime,
  pending downloads, module data and managed external NetEase files; shared
  Windows runtimes and independently installed third-party files are not owned by
  DropSpace. Directory scans do not follow reparse points.
- System Activities navigation and observer initialization are suspended together.
  Existing implementation/settings survive, including old enabled preferences;
  the release policy prevents them from starting. New settings remain off.
- About uses the existing logo and centered layout. Automatic installation is
  opt-in for Installer deployment; official source/manifest/size/hash checks and
  maintenance handshakes remain. Portable and MSIX keep their existing workflows.
- Home/changelog/Mac retain the shared website language and styles. Mac has
  independent validated feed, DMG/ZIP/checksums/notes, localized early/extremely
  unstable labels, responsive navigation, and safe static fallback. No Mac binary
  or compatibility claim is changed by this Windows release.
- The repository has no configured signing secrets. Exact v1.0.0 can use the
  documented unsigned distribution, signing if configuration becomes available.
  Future Stable releases retain their existing signing requirement.
- Optional AI models remain off by default and experimental. Existing model
  identities, prompts, runtime bytes and historical failures/unexecuted checks are
  preserved. A distinct release-specific stable-host authorization binds the
  owner's publication request and the unchanged Beta7 model record. This is not
  new semantic approval or a claim of new native-model evaluation.
