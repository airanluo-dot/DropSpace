# v0.3.1-beta.1 release coordination

Status: preparation only. A version-file change, local test pass or successful website
build is not a published release. Record the exact final commit and executed evidence
before checking off any gate below. Keep the published App/sites unchanged until their
coordinated release steps are authorized and ready.

## Scope and accepted Beta limits

- Optional/off-by-default Hy-MT2 plaintext translation: default 1.8B Q8_0 (about 1.9 GB),
  plus explicitly selected 7B Q8_0 (about 7.98 GB); each requires its own genuine runtime/semantic evidence
- First full-song generation can take minutes; known meaning errors remain disclosed
- Shared original/provider/AI lyric cache: 1 GiB default, 100 MiB–5 GiB range, excluding models
- Music-only lyric refresh; expanded-island-only next-line and lyric layout changes
- Fullscreen override off by default, with no exclusive-game/UAC visibility guarantee
- Drag compatibility card/experimental label removed; actual platform behavior unchanged

The accepted latency/translation-quality limitation does not clear unrelated implementation
bugs, supply native evidence or waive exact-commit build, test and packaging checks.
Historical candidate audits retain their original context; the final review must identify
which findings are fixed, accepted limitations, or still blocking.

## Before publication

- [ ] Push the complete latest candidate and record its exact SHA
- [ ] Run the requested fresh complete review on that revision; reconcile all findings
- [ ] Fix release-blocking findings and rerun affected review/tests on the final revision
- [ ] Confirm `RELEASE_VERSION` is `v0.3.1-beta.1`; PE/MSIX version is `0.3.1.1`
- [ ] Confirm the real installer lifecycle predecessor is `0.3.0-beta.32`
- [ ] Pass metadata, localization, Windows compatibility and security-policy checks
- [ ] Pass both localized Windows CI lanes and the complete release-validation workflow
- [ ] Verify the exact approved model, prompt/protocol, runtime bytes and release-gate evidence
- [ ] Pass App, WinUI, native-runtime, portable/installer lifecycle and artifact-version gates
- [ ] Record any physical-device/manual cases not executed as unverified, not passed
- [ ] Confirm final review and Windows evidence refer to the same source commit
