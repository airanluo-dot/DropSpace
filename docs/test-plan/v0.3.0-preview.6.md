# v0.3.0-preview.6 validation plan

Automated checks cover manifest traversal/limits/chunk counts, clipboard envelope integrity and loop eviction, AES-256-GCM/HKDF round trips, schema v1→v2 migration, preview byte/pixel bounds, action source safety, localization key parity, release metadata, and Worker syntax/static checks.

The Windows CI job must additionally run the existing app/installer/portable smoke suites and a manual two-device matrix:

1. pair two Windows 11 devices over a private network and compare SAS values;
2. transfer one file, a folder tree, a multi-file set, text, and a URL; approve, reject, cancel, reconnect, resume, and corrupt a chunk;
3. verify receive containment, whole-file hash, no source mutation, firewall-degraded messaging, and mDNS fallback;
4. exercise automatic/manual clipboard modes, stale reconnect, image limits, and loop prevention;
5. create/revoke/expire a Nearby share and download a range;
6. run the configured Worker receiver with a fragment key, verify browser-side decryption/hash checks, and confirm R2 contains only ciphertext;
7. verify that an unconfigured Internet Share path is reported as unavailable rather than successful.
