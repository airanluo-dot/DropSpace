# DropSpace v0.3.0-preview.10 P0 regression recovery test plan

This Preview is a release-blocking recovery slice for Smart Drag false
activation, Dynamic Island native border leaks, and incomplete Quick Action
exports. It preserves the Preview.9 shell-intake and Undo behavior. The release
is conditional until the hosted Windows and hands-on matrix below has evidence.

## Static and build gates

- Run release-version/consistency, localization parity, Windows compatibility,
  brand, and repository policy checks before restore.
- Run Core and Infrastructure tests, including every Smart candidate transition,
  late/duplicate probe callback rejection, export-directory policy, and atomic
  output-name collision tests.
- Build x64 Installer, Portable, and unsigned MSIX artifacts with the existing
  five-file release contract and minimum Windows build 17763.
- Confirm no Smart path reveals from a candidate event and no action path uses
  `Environment.CurrentDirectory` or a hidden image-size default.

## Smart Drag false-activation matrix

For each row record OS build, scale, monitor, source application, candidate
evidence, probe result, opacity/state, `WindowFromPoint`, and source cursor
feedback. Do not infer a pass from counters alone.

| Source / gesture | Expected before positive OLE evidence | Expected after positive file OLE evidence |
| --- | --- | --- |
| Empty desktop click/long press | No candidate reveal; no visible Island; no top-edge hit surface | N/A |
| Explorer blank area / marquee selection | No visible Island; probe may remain invisible and time-bounded | N/A unless a real file drag begins |
| Explorer exact file or folder | Candidate may be classified Strong, but remains invisible | Island reveals only after `CF_HDROP`/Shell/virtual descriptor proof |
| Desktop exact file or folder | Same as Explorer | Same as Explorer |
| Explorer non-file UI/text selection | No reveal; probe rejects or times out | N/A |
| Browser page, text selection, or browser drag | No reveal and no `DROPEFFECT_COPY` claim | N/A |
| Office/editor attachment or virtual file | No reveal while descriptors are pending | Reveal only after descriptor pair is positively classified |
| Accessibility drag-start without file payload | Intent is recorded, but no reveal | N/A |
| Pointer threshold without source classification | Invisible generic candidate only | Reveal only after positive OLE file evidence |
| Release before probe result | No reveal; late result cannot reopen session | N/A |
| Duplicate/stale probe result | No second reveal or state transition | Existing verified session remains single-owner |

Verify the probe remains one 144-pixel hollow target, no-activate/tool-window/
topmost, `DROPEFFECT_NONE`, and no more than 60 ms. Verify the source receives
no injected or suppressed input and no raw path/payload enters diagnostics.

## Dynamic Island native HWND matrix

- On Windows 10 1809 and Windows 11 24H2, exercise 100/125/150/175/200% scale
  on one, two, and three displays.
- Verify the Overlay remains borderless: no DWM frame, caption, resize border,
  corner artifact, or one-pixel leak around Compact, Drag Ready, Expanded, and
  Dismissing states.
- Verify the client rectangle and HRGN match the expected physical geometry
  after creation, placement edits, DPI changes, monitor changes, and repeated
  show/hide cycles.
- Force or observe each checked Win32/DWM failure path and verify the affected
  window stays hidden with a path-free numeric diagnostic.
- Verify Windows 10 uses the solid/base visual and Windows 11 optional DWM
  attributes never determine correctness.

## Quick Actions matrix

- Hash, ZIP, QR, resize, conversion, and metadata actions default to the
  dedicated DropSpace exports folder; choosing a folder is explicit and shown
  in the completion result.
- Seed an existing output name and verify the action creates a numbered new
  file without overwriting it or the current source.
- Resize requires width and height; conversion requires format and allows both
  optional size fields blank to preserve source dimensions; metadata stripping
  creates a new format-selected export.
- Exercise PNG/JPEG/BMP, missing source, inaccessible source/destination,
  malformed image, oversized image, cancellation, and output collision paths.
- Verify Main and Dynamic Island primary actions open the same parameter UX and
  execute through the same registry/capability authority. Verify results use
  localized actionable errors and never expose raw exception text by default.

## Release decision

Publish `v0.3.0-preview.10` only when the hosted Windows build and release
artifacts pass. Mark the release **CONDITIONAL** while historical Windows,
provider, DPI, border-leak, cursor-feedback, and manual Quick Action evidence
remains outstanding; Linux/static checks do not replace that evidence.
