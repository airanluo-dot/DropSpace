# DropSpace v0.3.0-preview.15 three-axis unified-hardening test plan

Preview.15 validates the native/OLE, motion/material/accessibility, DropLink/security, clipboard/update/storage, SSOT, and release-governance boundaries as one release slice. Hosted Windows checks establish build and packaging evidence only; real Windows and two-device rows remain explicit.

## Automated gates

- Core: native physical region signature identity, OLE payload capability classification, Smart Drag state/motion deduplication, topology enqueue recovery, motion token/profile separation, wall-clock catch-up, reduced-motion bounds, semantic resource contracts, placement validation, and policy limits.
- Infrastructure: DropLink actual-body hash/HMAC binding, pairing admission caps, nonce replay bounds, session lifetime/retention, single-flight completion/finalization, atomic exact chunk ledger, secret/revoke bounds, image/update/storage policy, database schema validation, and recovery behavior.
- App/Windows CI: Windows 10 Build 17763 target, x64 WinUI compile, installed image-codec preflight, OLE/Win32 boundary tests, localized resource policy, and hardcoding governance.
- Release: exact .NET 10 SDK/global.json policy, analyzer settings, deterministic brand assets, portable EXE, unsigned MSIX, installer lifecycle, SHA-256 sums, update manifest, release consistency, and official website contract.
- Website/Worker: release artifact kind contract, official repository/tag/download URL validation, runtime fallback behavior, Worker syntax/coordination tests, and no arbitrary artifact redirects.

## Evidence rules

Record OS build, display scale, monitor topology, deployment mode, branch/tag/commit SHA, exact command, test result, and relevant diagnostics. Never record file contents, full paths, plaintext share keys, or pairing secrets. A hosted Windows runner is not a substitute for the real OS/DPI/OLE/accessibility/two-device/Worker rows. Missing real-target rows are reported as PENDING REAL-WINDOWS EVIDENCE.
