# DropSpace v0.3.0-preview.9 shell, Quick Actions, and Undo test plan

This Preview validates the four usability features as one release slice while
preserving the Windows 10 version 1809 minimum, the existing Dynamic Island,
Smart Drag v2, and local-first/source-safe boundaries. It is conditional until
the required Windows evidence is attached to the release record.

## Static and build gates

- Run release version/consistency, localization parity, Windows compatibility,
  brand, and repository policy scripts before restore.
- Run the Core and Infrastructure test projects, including shell parser,
  Quick Action policy, schema 2 to 3 migration, pending-delete recovery,
  payload-sharing, and external-source safety tests.
- Build the x64 WinUI application, self-contained Portable EXE, unsigned MSIX,
  identity artifact, and per-user Inno Setup package.
- Run the installer lifecycle and both `en-US`/`zh-CN` Portable smoke lanes.
- Confirm the release manifest still reports minimum Windows build 17763 and
  exact asset names, sizes, hashes, channel, and release tag.

## Shell intake matrix

Record the OS build, deployment mode, language, selected item count, active
window, and resulting Space/Clipboard counts.

| Scenario | Installer | Portable | Expected result |
| --- | --- | --- | --- |
| Windows 10 1809 classic Explorer verb | Yes | No registration | Items enter Space; no foreground activation |
| Windows 11 classic verb / Show more options | Yes | No registration | Same bounded intake; no shell extension |
| SendTo single file/folder | Yes | No registration | Items enter Space with `sendto` acquisition kind |
| SendTo Unicode/space path | Yes | No registration | Exact path reference preserved |
| SendTo multi-selection | Yes | No registration | Bounded accepted batch; no duplicate process/window |
| malformed/oversized shell arguments | Yes | N/A | Rejected fail-closed; no raw path log |
| second shell invocation while app is running | Yes | N/A | AppInstance owner handles request without activating main window |

Verify the original external files remain present and unchanged. Verify the
Dynamic Island acknowledgement is localized, short-lived, and contains no file
name, source path, payload content, toast, or taskbar/Alt+Tab auxiliary window.

## Quick Actions matrix

- For File, Image, Text, and URL cards, verify Automatic uses current registry
  availability/order and exposes at most three primary actions.
- Configure each profile with valid unique IDs, `None`, and unavailable IDs;
  verify unavailable choices are skipped without replacement and More excludes
  only the actions actually shown as primary.
- Verify malformed persisted preferences recover to Automatic without changing
  non-UI settings.
- Verify settings changes update both the main item cards and Dynamic Island,
  and every primary button has a localized visible and automation name.
- Verify action execution still uses the existing registry/provider and retains
  source-safe output behavior.

## Undo matrix

- Remove one item, remove a batch, clear unpinned Clipboard history, pin, and
  unpin. Verify one InfoBar/Dynamic Island state, an eight-second expiry, and
  `Ctrl+Z`/button restoration.
- Verify a second remove/pin/clear finalizes the previous slot before exposing
  the new one.
- Verify pending rows disappear from normal list/search/count queries but keep
  exact IDs, metadata, timestamps, pin state, and payload references until Undo.
- Verify expiry, startup stale recovery, and graceful shutdown finalize rows;
  delete only unreferenced DropSpace-owned payloads and never external source
  files. Verify shared payloads remain until their final reference is gone.
- Verify retention cleanup remains non-undoable and does not reuse the active
  Undo slot.

Also record installer default-on task behavior, upgrade preservation, normal
uninstall, complete uninstall, startup hidden launch, redirected activation,
mixed-DPI overlay geometry, Explorer provider behavior, and no-focus status.

## Release decision

Do not infer historical Windows, Explorer/provider, SendTo, DPI, multi-monitor,
or manual Undo evidence from Linux checks or source inspection. Publish as
**CONDITIONAL** if the automated hosted Windows gates pass while manual evidence
remains outstanding; the release notes must state the boundary explicitly.
