# DropSpace v0.3.0-preview.14 motion-system test plan

Preview.14 tests the Dynamic Island presentation boundary without changing Smart Drag/OLE authorization, local data, or sharing contracts. Hosted Windows build/release output is evidence for build and packaging only; real Windows manual rows remain explicit.

## Automated gates

- Core tests: profile validity and channel separation; 60/120/144 Hz-equivalent bounded `dt` steps; reduced-motion no-overshoot/no-outward-scale; 1,000 state reversals; transition-cause descriptors; physical region signature/DPI/shape deduplication.
- App/Windows CI: compile with warnings as errors, Windows 10 Build 17763 target, Windows 11 optional capability probes, existing lifecycle/Smart/OLE/projection/packaging suites, and no continuous frame subscription after settling.
- Release: portable EXE, unsigned MSIX, installer, SHA-256 sums, update manifest, GitHub Release, website API/site, and the existing release-consistency gates.
