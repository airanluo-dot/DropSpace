# DropSpace v0.3.0-preview.23 Native Island UI refactor test plan

This plan maps the Preview.23 UI/UX refactor package to automated and hosted acceptance evidence. It does not infer physical Windows behavior from a Linux workspace or static source inspection.

## Automated acceptance mapping

| Area | Acceptance gate | Evidence |
| --- | --- | --- |
| Compact layout | Short content stays at the compact minimum; long lyrics clamp at the dynamic maximum; artwork, lyrics, spectrum, and controls remain inside the fixed-height surface | `CompactMediaLayoutCalculator` tests and Windows UI smoke |
| Media lifecycle | Playing media keeps the island active; paused/no-session media follows the idle policy; settings disable media/artwork/lyrics/spectrum/controls without stale bindings | Core policy tests, runtime source review, Windows smoke |
| Lyrics | Primary fallback is lyric → track title → source; secondary text is opt-in; delay and visibility settings remain bounded | Lyrics frame/runtime tests and target media evidence |
| Expanded pager | Default page is Music for playing media and Files otherwise; Files → Music → Widgets has no wrap; page size and transition remain within the one HWND | `ExpandedIslandPager` tests and Windows UI smoke |
| Files page | Three-to-five recent staged items render; an empty state offers Open DropSpace; direct drop uses the existing OLE intake path | View-model projection tests and Windows OLE evidence |
| Music page | Artwork/metadata/timeline/lyrics/spectrum and previous/play-next controls render; seek uses preview/debounce and reconciles failed requests | Media runtime tests and Windows SMTC evidence |
| Widgets | Expanded layout normalizes to the 6×3 grid; compact slots persist; Clock/Calendar/Resource/Settings are actual widget models | Widget policy tests and settings round-trip test |
| Window boundary | One island HWND, no XAML outer stroke, DWM corner/backdrop capability gating, transparent inner surface, no focus stealing, and no `SetWindowRgn`/DWM visual mismatch | App boundary tests, static policy checks, and Windows visual smoke |
| Settings | Music and Settings are first-class Main sections; settings categories are split; no plugin/custom-font/native-volume-flyout/Liquid-Glass controls are exposed | XAML/resource policy checks and UI smoke |
| Migration | Schema 12 → 13 preserves nested media, lyrics, appearance, widget, notification, volume, and placement values; fresh defaults match the Preview.23 contract | Infrastructure migration fixtures |
| Localization | en-US and zh-CN keys/placeholders remain identical and new controls resolve through resources | `Test-Localization.ps1` |
| Compatibility | Build 20348/x64/.NET 10/WinUI 3 and all package/update surfaces stay aligned | `Test-WindowsCompatibility.ps1` |
| Packaging | Release version, five public assets, checksum, update manifest, website/API publication, and default-branch SHA agree | Windows Release, website deploy, and live verification workflows |

## Required hosted suites

- Core, Infrastructure, and App tests with locked restore.
- Release-version/consistency, localization, compatibility, hardcoding, secret-hygiene, and brand-asset gates.
- WinUI Release build, x64 portable EXE, unsigned MSIX, identity package, Inno installer, installer lifecycle, and en-US/zh-CN portable smoke.
- Post-publication GitHub Release asset/hash checks and official website release API synchronization.

## Physical evidence boundary

Record results on Windows build 20348 and Windows 11 for SMTC players, local/online LRC, notification permission denied/allowed, endpoint changes, process-loopback availability/fallback, 100–200% DPI, one/two/three monitors, sleep/resume, Explorer/Desktop and provider OLE, keyboard/accessibility navigation, and long-run timers. Until those rows are recorded, they remain `CONDITIONAL`.

## Release gate

The final release tag is `v0.3.0-preview.23`. Preview.22's tag, release, assets, and history must remain untouched. Publication uses the exact `publish/v0.3.0-preview.23` bridge branch pointing at the merged `main` commit.
