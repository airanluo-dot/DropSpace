# Artist orthography data

`TSCharacters.txt` is the unmodified Apache-2.0 OpenCC character dictionary at commit
`3ac34aa439a9908dd49fa92b5174b46314787ac2`:
https://github.com/BYVoid/OpenCC/blob/3ac34aa439a9908dd49fa92b5174b46314787ac2/data/dictionary/TSCharacters.txt

SHA-256: `9ff46a7d30e5765375eb13d33f2b03a34d298913caf2b120380679f33ae1642d`.
The adjacent original license and dictionary are embedded in the Core assembly.
Only single-rune, single-result entries are used; ambiguous multi-result mappings are skipped.
This is conservative whole-credit orthographic normalization, not transliteration or artist
entity knowledge. Canonical metadata is preserved. No artist-specific names are in the rules.
